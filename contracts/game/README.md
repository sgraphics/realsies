# Realsies game contract

Live on testnet at `game.realsies.testnet` since 2026-11-04 (wasm sha256 in `realsies_game.wasm.sha256`). Rust, near-sdk 5.29.1. Formats and rules: `docs/spec.md` section 3.

## Build and test

```
cargo test                                     # 14 unit tests; on Windows set AWS_LC_SYS_PREBUILT_NASM=1
cargo build --release --target wasm32-unknown-unknown
wasm-opt -Oz target/wasm32-unknown-unknown/release/realsies_game.wasm -o realsies_game.wasm
```

The unit tests verify the real NEAR AI enclave signature from `experiments/near-ai/evidence/2026-11-04/`, a full round with exact settlement numbers, a proof reused for another viewer being rejected, unanimity both ways, refunds, and the guards. `tests/vectors.json` is generated by `tests/gen_vectors.py` with a public throwaway key.

`scripts/smoke-chain.sh` runs the same flow on a throwaway copy on testnet. Its 2026-11-04 run: two proofs assigned with on-chain ecrecover, balances exact (40, 56.15, 1.9, 0.95, 1.0 tREAL), withdraw delivered.

## Calls

All amounts are base units as decimal strings. `round_id` is a JSON number. Hex is lowercase without `0x` except Ethereum addresses and signatures.

| Method | Signer | JSON args | Deposit |
|---|---|---|---|
| `ft_transfer_call` on the token | depositor | `{"receiver_id":"game.realsies.testnet","amount":"100000000000000000000","msg":"{\"for\":\"ana.realsies.testnet\"}"}` (`msg` may be `""` to credit the sender) | 1 yocto, 100 Tgas |
| `withdraw` | player | `{"amount":"5000000000000000000"}` | 0, 50 Tgas |
| `transfer` | any holder | `{"to":"ana.realsies.testnet","amount":"..."}` | 0 |
| `start_round` | operator | `{"round_id":1,"secret_hash":"<64 hex>","ends_at_ms":1793900000000}` | 0 |
| `commit_characters` | operator | `{"round_id":1,"items":[{"character_id":"<32 hex>","commitment":"<64 hex>"}]}` | 0 |
| `play` | player | `{"round_id":1,"handle":"<64 hex>","coins":5}` | 0 |
| `call` | player | `{"round_id":1,"handle":"<64 hex>","human":true}` | 0 |
| `end_round_now` | operator, test mode | `{"round_id":1}` | 0 |
| `reveal_round` | operator | `{"round_id":1,"secret":"<64 hex>"}` | 0 |
| `open_characters` | operator | `{"round_id":1,"openings":[Opening, ...]}` | 0, up to 300 Tgas |
| `settle_round` | operator, or anyone after the open window | `{"round_id":1}` | 0, 100 to 300 Tgas |

`Opening` for a bot:

```json
{"character_id":"<32 hex>","kind":"bot","salt":"<64 hex>","payout":"bots.realsies.testnet",
 "model":"z-ai/glm-5.3-flash","prompt_hash":"<64 hex>","signers":["0x3b75..."],
 "proofs":[{"viewer":"ana.realsies.testnet","text":"z-ai/glm-5.3-flash:<64 hex>:<64 hex>","signature":"0x<130 hex>","request":"<exact request bytes>"}]}
```

For a human: `{"character_id","kind":"human","salt","payout","account":"ben.realsies.testnet","viewers":["ana.realsies.testnet"]}`.

The contract lowercases, sorts and dedups `signers` before building the commitment preimage, so commit them that way. `open_characters` returns one report per opening and never fails the whole call for a bad proof:

```json
[{"character_id":"a999d31afb79a1bbaaa6af316649c52a","ok":true,"assigned":2,"rejected":[]}]
```

Rejection reasons are `"<viewer>: <why>"`, for example `ben.realsies.testnet: message 1 does not carry this chat's tag`, or for the opening itself `commitment mismatch` with `ok: false`. Re-opening the same character with more proofs or viewers is allowed.

Timing rules: plays need `now < ends_at_ms`; calls need `now <= ends_at_ms + 60 000`; `reveal_round` needs `now > ends_at_ms + 60 000`; a play counts for a character only if its block height is greater than the character's commit height. `end_round_now` sets `ends_at_ms = now - 60 001`, so reveal works from the next block.

## Views

`get_config {}`:

```json
{"owner":"realsies.testnet","operator":"ops.realsies.testnet","token":"real.realsies.testnet","coin_unit":"1000000000000000000",
 "fund":"fund.realsies.testnet","house":"house.realsies.testnet","test_mode":true,"latest_round":null,
 "params":{"fee_bps":500,"right_bps":7000,"character_bps":2000,"min_coins":5,"max_coins":500,"call_grace_ms":60000,"open_window_ms":3600000}}
```

`balance_of {"account_id"}` returns `"<base units>"`.

`get_round {"round_id"}` returns null or:

```json
{"round_id":1,"secret_hash":"…","started_ms":1793800000000,"ends_at_ms":1793800600000,"secret":null,"status":"open","characters":["…"],"plays":3}
```

`status` is `open`, `revealed` or `settled`.

`get_character {"round_id","character_id"}` returns null or:

```json
{"character_id":"…","commitment":"…","committed_height":276230000,
 "opened":{"kind":"bot","payout":"bots.realsies.testnet","model":"z-ai/glm-5.3-flash","prompt_hash":"…","signers":["0x…"],"account":null,"opened_height":276230500},
 "result":{"plays":2,"right_coins":"9500000000000000000","wrong_coins":"9500000000000000000","character_payout":"1900000000000000000","house":"950000000000000000"}}
```

`get_play {"round_id","handle"}` and `get_round_plays {"round_id","from_index"?: 0,"limit"?: 100}` return:

```json
{"handle":"…","account":"ana.realsies.testnet","coins":10,"locked":"9500000000000000000","fee":"500000000000000000",
 "call":true,"played_height":276230100,"played_ms":1793800100000,"character":"…","outcome":"wrong","credited":"0"}
```

`outcome` is null until settlement, then `right`, `wrong` or `refund`; `credited` is what the play paid back (refund, or locked plus reward).

## Events

Every state change logs `EVENT_JSON:{"standard":"realsies","version":"1.0.0","event":…,"data":[…]}` with events `deposit, withdraw, withdraw_failed, transfer, round_started, characters_committed, play, call, round_ended_early, round_revealed, character_opened, round_settled`.
