# Credits

All art in this package is drawn procedurally in code (TypeScript pixel maps and painters).
No external image files are used.

- Master palette: **ENDESGA 32** by ENDESGA (https://lospec.com/palette-list/endesga-32),
  a free palette; colours only, no artwork copied.
- Fonts are not part of this package. The web app self-hosts, via @fontsource (SIL Open Font License 1.1):
  **Press Start 2P** by CodeMan38 (headings, buttons) and **Pixelify Sans** by Stefie Justprince (chat and body text).
